- 기준 문서: `docs/superpowers/specs/2026-10-05-momeokjo-design.md` (R1~R33, Q1~Q5)

  - 거점 선택: 봉은사역(기본) / 동대문역사문화공원역. 설정은 `shared/hubs.ts`

  - "근처 상위 N%" 배지 (R34, `shared/rank.ts`)

  - 익명 사용 통계: `POST /api/events`, 토큰으로 여는 `/admin` 통계 페이지
  - 문구 "점심 ㄱ?" → "점심 고?"
  - 무료 플랜 제약: CPU 10ms, 외부 subrequest 50회, D1 일일 쿼터. 비공식 카카오 상세 API는 실패하거나 403을 줄 수 있음

## 1. 페르소나와 사용자 여정

모든 여정은 **시크릿 창(저장값 없음)**에서 시작한다. 단계마다 "기대 결과"와 Pass/Fail 기준을 함께 적었다. 표의 ✅는 통과 조건이다.

### P1. 점심 5분 전, 급한 팀장 "김팀장"

- **목표:** 4명 이상, 1시간 안에 다녀올 곳을 1분 안에 정해서 팀 단톡방에 3곳을 던진다.

- **상황:** 11:55, 봉은사역 근처 사무실. 화면을 처음 연다. 4명이라 분식은 빠져야 하고 예약되는 곳이면 더 좋다.

### 3.3 curl 스모크 스크립트 (개요) — 2026-10-06: `scripts/smoke.sh`로 대체 (아래 초안은 예전 좌표 API 기준)

`scripts/smoke.sh` 초안이다. 운영에 부담을 주지 않도록 **거점 좌표만** 쓰고, 요청은 모두 합쳐 20번 안쪽으로 한다(IP당 분당 10회 제한과 카카오 쿼터 보호).

```bash
#!/usr/bin/env bash
# 사용: B=https://mmj.itmz.me ./scripts/smoke.sh   (관리자 항목은 ADMIN_TOKEN이 있을 때만)
set -uo pipefail
B=${B:-https://mmj.itmz.me}
fail=0
ok()  { printf "  ok   %s\n" "$1"; }
bad() { printf "  FAIL %s\n" "$1"; fail=1; }
code() { curl -s -o /dev/null -w "%{http_code}" "$@"; }

echo "== 정적"
[ "$(code "$B/")" = 200 ] && ok "index 200" || bad "index"
curl -s "$B/" | grep -q "점심 고?" && ok "title 점심 고?" || bad "title이 아직 예전 문구"
[ "$(code "$B/og.png")" = 200 ] && ok "og.png" || bad "og.png"
[ "$(code "$B/some/spa/path")" = 200 ] && ok "SPA 폴백" || bad "SPA 폴백"
[ "$(code "$B/api/health")" = 200 ] && ok "health" || bad "health"

echo "== 목록 (거점마다 1번, 500m)"
for hub in "bongeunsa 37.514255 127.060234" "ddp 37.5651 127.00749"; do
  set -- $hub
  out=$(curl -s --compressed -w '\n%{http_code} %{time_starttransfer} %{size_download}' "$B/api/places?lat=$2&lng=$3&radius=500")
  meta=$(tail -1 <<<"$out"); body=$(sed '$d' <<<"$out")
  read -r http ttfb size <<<"$meta"
  n=$(jq '.places|length' <<<"$body"); pending=$(jq '.pending' <<<"$body"); stale=$(jq '.stale' <<<"$body")
  [ "$http" = 200 ] && [ "$n" -gt 20 ] && ok "$1 200, ${n}곳" || bad "$1 http=$http n=$n"
  [ "$pending" = 0 ] && ok "$1 pending 0" || bad "$1 pending=$pending (warm 필요)"
  [ "$stale" = false ] || bad "$1 stale"
  awk "BEGIN{exit !($ttfb < 2.0)}" && ok "$1 TTFB ${ttfb}s" || bad "$1 TTFB ${ttfb}s"
  jq -e '[.places[] | keys[]] | unique - ["category","detail","distance","group","id","lat","lng","name","photoUrl","url","walkMinutes"] | length == 0' <<<"$body" >/dev/null \
    && ok "$1 목록 원소 키" || bad "$1 목록 원소에 예상 밖 키"
done

echo "== 입력 검증 (외부 호출이 일어나지 않는 요청만)"
[ "$(code "$B/api/places?lat=abc&lng=127&radius=500")" = 400 ] && ok "lat 문자 400" || bad "lat 문자"
[ "$(code "$B/api/places?lat=37.514255&lng=127.060234&radius=1001")" = 400 ] && ok "반경 1001 400" || bad "반경 상한"
[ "$(code "$B/api/places?lat=37.514255&lng=127.060234&radius=99")" = 400 ] && ok "반경 99 400" || bad "반경 하한"
[ "$(code "$B/api/places?lat=37.5&lng=127&radius=500")" = 400 ] && ok "거점 아닌 좌표 400" || bad "거점 아닌 좌표 허용 (A-1)"
for id in abc 1234567890123456 -1 "1%20OR%201=1"; do
  [ "$(code "$B/api/places/$id")" = 404 ] && ok "id $id 404" || bad "id $id"
done
[ "$(code "$B/api/places/13583324")" = 200 ] && ok "단건 200" || bad "단건"

echo "== 이벤트"
[ "$(code -X POST -H 'content-type: application/json' -d '{"name":"smoke_test","hub":"bongeunsa"}' "$B/api/events")" = 400 ] \
  && ok "모르는 이벤트 400" || bad "모르는 이벤트 허용"
big=$(head -c 4096 /dev/zero | tr '\0' a)
[ "$(code -X POST -H 'content-type: application/json' -d "{\"name\":\"draw\",\"x\":\"$big\"}" "$B/api/events")" = 413 ] \
  && ok "큰 본문 413" || bad "큰 본문 허용"
# 정상 이벤트는 운영 통계를 오염시키므로 스모크에서는 보내지 않는다 (또는 "smoke" 플래그로 집계에서 빼기)

echo "== 관리자"
[ "$(code "$B/api/admin/audit?lat=37.514255&lng=127.060234&radius=100")" = 401 ] && ok "토큰 없이 401" || bad "관리자 열림"
[ "$(code -H 'Authorization: Bearer wrong' "$B/api/admin/audit?lat=37.514255&lng=127.060234&radius=100")" = 401 ] && ok "틀린 토큰 401" || bad "틀린 토큰"
if [ -n "${ADMIN_TOKEN:-}" ]; then
  for hub in "37.514255 127.060234" "37.5651 127.00749"; do
    set -- $hub
    curl -s -H "Authorization: Bearer $ADMIN_TOKEN" "$B/api/admin/audit?lat=$1&lng=$2&radius=1000" \
      | jq -e '.pass.q1 and .pass.q2' >/dev/null && ok "audit $1,$2 Q1·Q2" || bad "audit $1,$2"
  done
fi

exit $fail
```

통과 기준: 종료 코드 0. 배포 직후와 매일 아침 11시(점심 전) 한 번 돌린다. "거점 아닌 좌표 400"과 "모르는 이벤트 400", "큰 본문 413"은 해당 수정이 배포되기 전까지 FAIL이 정상이다(알려진 실패로 표시).
