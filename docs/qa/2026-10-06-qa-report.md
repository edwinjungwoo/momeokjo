## 5. 남은 P2 (나중에)

1. **터치 영역 44px 미만**: 인원·예산·평점 세그먼트 34px, 카테고리 칩·거점 칩·정렬 36px (높이). WCAG 2.2 AA(24px)는 넘고 칩 사이 8px 간격이 있지만 Apple HIG 44pt보다 작다. 세그먼트 컨테이너를 44px로 키우는 정도가 쉬운 개선.
2. **연타 쿨다운 없음(S-1)**: 동작 줄이기에서 뽑기를 10번 연타하면 뽑기 10번(매번 새 3곳, `drawnIds`가 빨리 차서 초기화 토스트가 일찍 나옴). 오류는 없음.
3. **`/api/events` Origin 확인 없음(A-3 일부)**: 다른 사이트에서도 올바른 봉투를 보내면 통계가 오염될 수 있다. 쿼터는 익명 id별 제한과 D1 쓰기 소프트 한도가 막는다.
4. **관리자 API 요청 제한·상수 시간 비교 없음(A-2)**: 토큰이 길면 실익은 작다.
5. **pending이 줄지 않는(강등 아닌) 거점의 재방문자 자동 뽑기가 약 30초 늦음**: 폴링 10번이 끝나야 뽑는다(R39 의도). 운영에서 pending이 0이면 해당 없음 — 스모크의 pending WARN으로 본다.
6. **`/admin/`(끝 /)는 관리 화면이 아니라 앱이 뜬다**: `web/main.tsx`의 `pathname === "/admin"`. `_headers`의 `X-Robots-Tag`도 `/admin`에만 붙는다.
7. **QA 도구 메모**: 헤드리스 Chrome의 Event Timing `duration`은 롱태스크가 없어도 0.5~4초가 찍히는 경우가 있어(프레임 제시 지연) 탭 지연은 "클릭 → rAF 뒤 첫 작업"으로 쟀다. 실기기 INP는 배포 뒤 확인.
